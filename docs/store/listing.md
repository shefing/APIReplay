# Chrome Web Store listing draft

## Name

API Replay

## Short description

Record and replay API traffic in Chrome for debugging, QA, demos, and deterministic frontend testing.

## Detailed description

API Replay helps developers and QA teams capture real API traffic and replay it on demand.

### Core capabilities

- Record API/network calls using URL filters.
- Replay captured calls with optional fallback matching.
- Edit mocked response bodies and status codes.
- Enable/disable specific requests for replay.
- Save and reuse filter presets.
- Search requests by URL, method, or status.
- Configure replay latency to simulate production-like conditions.
- View replay stats (matched/unmatched and hit counters).

### Privacy and security

- Data is stored locally in your browser.
- No backend account is required.
- No remote script execution.
- Import data is validated before persistence.
